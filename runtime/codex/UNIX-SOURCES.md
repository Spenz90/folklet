# Bundled Unix helpers

Crew's macOS and Linux releases preserve the unmodified official Codex 0.153.4 package layout. Windows uses its separate flat runtime. The versioned URLs and exact archive/executable hashes are recorded in `scripts/platform-dependencies.json` and each assembled release's `runtime/platform-runtime.json`.

- Codex and its code-mode helper: [OpenAI Codex release](https://github.com/openai/codex/releases/tag/rust-v0.153.4), source commit `3d2ee51ca2d5db578f328aa75e20aa22c0197c9a`. See `LICENSE` and `NOTICE`.
- ripgrep 15.2.0: [upstream source](https://github.com/BurntSushi/ripgrep/tree/15.2.0). See `RIPGREP-COPYING`, `RIPGREP-LICENSE-MIT`, and `RIPGREP-UNLICENSE`.
- Patched zsh: [upstream source revision](https://github.com/zsh-users/zsh/tree/77045ef899e53b9598bebc5a41db93a548a40ca6), with OpenAI's [exec-wrapper patch](https://github.com/openai/codex/blob/rust-v0.134.0-alpha.3/codex-rs/shell-escalation/patches/zsh-exec-wrapper.patch). The [official build workflow](https://github.com/openai/codex/blob/rust-v0.134.0-alpha.3/.github/workflows/rust-release-zsh.yml) and [build script](https://github.com/openai/codex/blob/rust-v0.134.0-alpha.3/.github/scripts/build-zsh-release-artifact.sh) record its source and build procedure. Codex 0.153.4 pins this helper through its [zsh manifest](https://github.com/openai/codex/blob/rust-v0.153.4/scripts/codex_package/codex-zsh). See `ZSH-LICENCE`.
- Linux bubblewrap helper: [corresponding source](https://github.com/openai/codex/tree/3d2ee51ca2d5db578f328aa75e20aa22c0197c9a/codex-rs/vendor/bubblewrap), [Rust wrapper and build instructions](https://github.com/openai/codex/tree/3d2ee51ca2d5db578f328aa75e20aa22c0197c9a/codex-rs/bwrap), and [complete source archive](https://github.com/openai/codex/archive/3d2ee51ca2d5db578f328aa75e20aa22c0197c9a.tar.gz). See `BUBBLEWRAP-COPYING` for the GNU Library General Public License, version 2. Preserve this notice and access to the corresponding source when redistributing the Linux binary.

These are separate, unmodified helper programs; their licenses do not replace Crew's own license. Their inclusion is not an endorsement by their authors. The bundled zsh executable requires macOS 15 or later, or on Linux glibc 2.38 or later and `libtinfo.so.6`.

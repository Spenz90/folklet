## Release packaging checks

The 0.6.1 public source list contains **178 explicitly listed files**: modules, tests, setup scripts, native helper source, cloud templates and documentation. The earlier 0.6.0 source folder and ZIP contained 158 files; those older desktop archives are not 0.6.1 release assets. Source bytes are checked against the intended app source in every new desktop archive. Releases exclude local chats, account files, browser profiles, private app drafts/backups and generated logs. The source archive also excludes downloaded dependencies and compiled binaries. The scanner rejects personal absolute paths and common secret formats; this is a safeguard, not a general secret-detection guarantee.

Windows packaging checks the positive file list and bundled runtime hashes. Mac/Linux packaging additionally verifies the exact runtime receipt against pinned publisher manifests, archived runtime hashes, executable permissions, safe framework links and absence of duplicate paths. Every output gets a SHA-256 checksum. The optional Tailscale installer is omitted from public archives.

Older cross-assembled Mac previews did not contain a compiled native Mac control helper or pass a Mac launch test. The 0.6.1 workflow compiles the matching helper, applies a local ad-hoc signature, launches each packaged desktop and retains evidence. Only a successful run for the release commit establishes those results. The [first workflow attempt](https://github.com/Spenz90/folklet/actions/runs/34097609755) exposed macOS temporary-path aliases and Git notice-byte normalization issues; fixes are included in this source. Ad-hoc signing does not establish an Apple publisher identity or notarization.
